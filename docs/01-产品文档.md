# MTS（Mazu Trade System）产品文档

> 版本：v2.8.0 ｜ 定位：轻量级外贸企业管理平台 ｜ 本文档基于系统代码实际实现编写，描述产品当前真实具备的功能。

---

## 一、产品愿景

MTS 是一套面向中小型外贸企业的**轻量级全流程管理平台**，把外贸企业最核心的「接单—备货—发货—开票—收款」主链路，以及背后的采购、委外、库存、退税、财务核算，全部放进同一个系统。

产品的设计哲学是「**以销售订单为源头，一条线索管到底**」：一张销售订单审核后，每一行明细可以独立选择**转直采（买成品）**或**转外发（委外加工）**两条路线之一——直采行由采购订单买成品交付，委外行的材料走独立材料采购入库、领料出库时才挂回销售单归集成本；后续的采购单、委外单、领料单、入库单、发货单、发票、应收应付全部由系统按单据链自动串联、自动核算、自动预警，业务员不需要在多个系统之间来回搬运数据。

与大型 ERP 相比，MTS 刻意保持了「开箱即用」的轻量：单文件数据库、一键安装脚本、内置角色权限、中文界面，适合 10～200 人规模的外贸工厂与贸易公司快速上线。

## 三、核心功能模块

### 3.1 管理驾驶舱（工作台）

登录后首页即决策视图，所有数据实时来自业务单据：

- **现金收支趋势**：近 6 个月收款、付款按月汇总柱状对比，可钻取某月的收付款明细单。
- **应收账款账龄**：余额大于零的应收按逾期天数排序，标出到期日与逾期天数。
- **应付账款账龄**：同上，按供应商汇总。
- **销售毛利榜**：按发货单逐一计算「收入 − 出库成本」，退货自动负向冲减；支持按产品钻取到每一笔发货的收入、成本、毛利与毛利率。

**业务价值**：老板不用等财务月结，随时掌握现金与盈利真相；毛利直接追溯到每张发货单的出库批次成本，杜绝「账面盈利、实际亏损」。

### 3.2 基础档案

所有业务的唯一数据源，全部支持停用保护与删除保护（有业务数据的档案只能停用、不能删除）：

- **原辅材料**：编码、大类/小类（字典可配）、型号规格、计量单位、采购参考价、默认供应商。
- **产品档案**：产品编码、中英文名、规格、单位、销售价、预估成本、HS 编码（选择后自动回填征/退税率）、是否可外购；支持**按客户维护产品资料**（客户专属料号、价格）。
- **BOM 管理**：产品的材料构成（用量 + 损耗率）与工艺路线（工序顺序）一屏维护，上下分栏、可拖动调整行序，是委外领料量计算的基础。
- **客户 / 供应商**：编码自动预生成、双语名称、税号、地址、联系人、付款条件、**账期天数**（自动计算应收/应付到期日）、信用额度；供应商类型支持「原材料 / 委外 / 辅料」，**委外加工商就是「委外」类型供应商**，无需单独维护一套档案。
- **工序管理**：企业自有工序库（编码自动 GX 生成），供产品工艺路线引用。
- **参数设置**：供应商类型、材料类别、计量单位、付款方式、国家、仓库类型、加工工序等全部业务字典，按分组维护、自动编号，页面上所有下拉框都来自这里。
- **仓库管理**：仓库编码（WH 自动编号）、类型（原辅料仓库 / 成品仓库）、地址、负责人；入库收货时系统按类型自动匹配仓库。
- **币种/汇率**：内置人民币、美元、欧元、日元、英镑、港币、澳元七种常用币种；汇率支持**手工维护**与**一键获取最新汇率**（国内数据源，每个工作日早上 9 点自动拉取一次），同币种同日期自动去重，业务单据按当日汇率折算本币。

**业务价值**：一处维护、全局引用；档案的删除保护 + 停用机制保证历史单据永远不会变成「死链接」。

### 3.3 销售管理

覆盖「报价 → 订单 → 备货分流 → 发货 → 报关 → 开票 → 收款」全链路。

- **报价单**：快速给客户报价（产品、数量、外币单价、有效期），一键转销售订单。
- **销售订单**：多明细行订单，支持外币 + 汇率 + 付款条件（TT/LC/DP/DA）；订单走「待审核 → 已审」流程。
- **两路分流（核心能力）**：订单审核后，**每一行明细独立选择备货方式**：
  - **转直采（买成品）**：贸易型，直接把成品买进来交给客户 → 流入采购管理，**按成品本身生成采购订单**（无视 BOM）；
  - **转外发（委外加工）**：委外加工型 → 流入委外管理，**不关联采购订单**；材料由采购员单独填采购订单入库，委外领料时从原料库出库、成本挂到销售单。
  两条路线**互斥**：一行明细选定路线后另一条自动锁定，从机制上杜绝「同一行货既在采购又在委外」的混乱。
- **明细行变更与停售**：审核后的订单明细仍可在规则内变更（数量、新单价等），也可整行停售；所有变更受状态机保护，下游已产生单据时会明确提示先处理下游。
- **两段式发货**：业务员「通知发货」→ 仓管员在成品出库按批次实际出库 → 明细行确认「发货完成」。库存扣减权在仓管手里，业务与仓储职责分离。
- **销售退货**：按原发货单退回，货回原批次、成本按原发货成本冲回；若订单已开票，系统提示需同步红冲发票；若关联报关单已申报退税，退货单自动打「已报税」标记，次月申报自动带出负数冲减。
- **报关管理**：报关单 + 报关商品行（一票报关可含多商品、多 HS 编码），记录 18 位报关单号、申报金额、报关行，状态流转「已报关 → 已放行 → 已结关」，是退税申报的出口端数据源。（注：该页面在当前版本界面中暂未开放入口，能力已在系统内就绪。）
- **销售发票（含红冲）**：蓝字开票金额受「订单未开票金额」上限控制；开错票走**全额红冲**——系统自动生成负数发票与负数应收，原票标记「已红冲」，红字票禁改禁删，审计链完整。
- **应收账款**：开票自动生成，到期日 = 发票日 + 客户账期；支持**退款登记**（负数收款）与**核销转移**（把红字应收与同客户正余额应收对冲，全程留痕）。
- **收款管理**：收款单按应收到期日顺序自动核销；收款单经财务「审核」后业务锁定，防止事后篡改。

**业务价值**：一张订单从签下到收齐款，每个环节谁在做、做到哪一步、卡在哪，系统里一目了然；财务红冲/退款/核销全部按会计规范留痕。

### 3.4 采购管理

采购分两条互相独立的线：**成品采购**（由销售订单驱动）与**材料采购**（完全独立）。

- **销售订单转采购（只关联买成品的行）**：只有「转直采」的明细行进入本列表，系统按**成品数量 ×（1 + 损耗率）**生成成品采购需求（**无视 BOM**，买成品本身，不展开材料行）；采购员指定供应商与单价，系统按供应商自动拆分成多张采购订单；采购量超过「需求数量 ×（1 + 损耗）」会被硬性拦截。
- **材料采购完全独立**：原材料采购与销售订单**零关联**——采购员单独填写采购订单买材料 → 转原料库入库（明细不挂销售单）；材料成本在委外**领料出库**时才按 FIFO 挂到销售单归集。
- **采购订单**：审核 / 反审核 / 修改 / 退回，全状态机管理；由销售订单转来的订单禁止直接改明细（保证与销售单联动一致），只能退回重转。
- **入库双轨**：采购明细可「转成品库入库」（转直采的成品）或「转原料库入库」（独立采购的材料），生成待入库单由仓管收货；两轨互斥防重复入库。
- **采购入库**：收货自动生成**批次号**，按订单单价写入批次成本，并回写材料「最新采购价」/产品「最新成本价」；支持分批收货。
- **取消入库与红冲**：批次没动过可整单取消（自动补冲销流水保留审计）；批次已被领用的场景，系统会明确提示先到委外页退回领料或走「红冲」，支持**多次部分红冲**。
- **采购发票**：发票号重复直接拦截；「增值税专用发票 / 海关进口缴款书 / 农产品收购发票」等可抵扣类型**自动同步生成退税进项发票**；开票自动生成应付账款，到期日 = 发票日 + 供应商账期。
- **付款管理**：付款自动核销应付；付款单财务审核后锁定。
- **应付账款**：展示每张应付的余额、账期、已付，提供「应付-付款」对照明细表。

**业务价值**：成品采购由销售单驱动、该买多少系统算；材料采购独立灵活、成本在出库（领料）时才精确归集到单；入库成本自动进批次台账，毛利核算有了准确源头。

### 3.5 生产管理（已下线）

### 3.6 委外管理

委外（外发加工）从生产模块独立成线，业务模型按「订单级简化」设计：

- **销售订单转委外**：对「转外发」的明细行，按产品工艺路线逐道工序生成委外加工单（**每道工序一张单**，指定加工商、委外数量、加工单价）；不需要委外的工序可删除，后续还能一键恢复全部工序。委外行**不关联采购订单**。
- **订单级供料方式**：整个委外订单统一选择「己方提供」或「包工包料」：
  - **己方提供**：须先完成**领料**——领的是原料库中的库存，系统按「成品数 × BOM 用量 ×（1 + 损耗）」算出应领清单，从仓库**按总量 FIFO 跨批次扣料**并生成原料出库流水（挂销售单号），材料成本就此归集到该销售单；材料不足会明确提示缺口，先走独立材料采购补库。
  - **包工包料**：加工商自备料，无需领料。
- **委外订单审核**：审核即生成**加工费应付账款**（按供应商、按工序分单结算）；只有**末道工序**的委外单会生成成品待入库单，保证成品只在最后一道工序完成后回仓。
- **反向操作齐全**：反审核（已付款/已入库的拦截）、删除委外单（已领材料自动退回原批次、销售明细行解锁回「未生产」）、领料退回、完成/取消完成/退回。

**业务价值**：老板视角「每个加工商我只管单价和数量」，领料成本系统自动归集；加工费应付与成品入库环环相扣，不会出现「货回来了、账没回来」。

### 3.7 库存管理

以**批次**为核心的全仓管理：

- **库存收发存**：按批次展示库存余额与成本，支持「快照」与「期间」两种口径（期初 + 收入 + 发出 = 期末），可按仓库/物料/日期区间查询。
- **待入库单收货**：采购/生产/委外的入库统一走「待入库单」，仓管确认收货时自动匹配仓库、生成批次；支持分批收货（收满自动完成）、整单退回、退数量。
- **成品出库**：与销售两段式发货联动；出库时批次下拉明确显示「某数量已锁定给某订单」，防止把已承诺的货发给别人；支持出库退回。
- **原料出库**：手动出库（如研发领料、报销料耗）FIFO 扣批次，单据可退回。
- **盘点管理**：新建盘点自动带出仓库全部批次账面数，录实盘后提交，系统按差异自动生成盘盈/盘亏流水；盘亏不允许超账面；支持盘「账外批次」（有货无账）。
- **批次追溯**：任一批次一条时间线看清「什么时候从哪张单进来、什么时候被哪张单出出去」，进销存全链路可溯源。

**业务价值**：外贸企业最怕货与账对不上，批次级台账 + 全单据留痕让每次盘点差异都能追到具体单据和责任人。

### 3.8 退税申报（生产企业免抵退）

> **版本说明**：退税模块后端能力已完整实现（免抵退计算、进项发票、申报表、负数冲减），但在 v2.8.0 界面中**暂未开放菜单入口**（代码保留，计划后续版本发布）。以下为模块已具备的能力。

- **免抵退自动计算**：录入出口 FOB 金额、征退税率、内销税额、进项税额、上期留抵，系统自动算出**免抵退税不得免征和抵扣税额、应纳税额、期末留抵、免抵退税额、应退税额、免抵税额**。
- **进项发票池**：采购端可抵扣发票自动汇入，跟踪认证状态与退税匹配状态。
- **申报表**：按「所属期 + 批次」建申报表；明细行**双端匹配**——出口端选已放行/已结关的报关商品行（自动带出商品、数量、FOB 金额、HS 退税率），采购端选进项发票（自动带出凭证号、税号）；每行自动算退税额。
- **负数申报（出口退运冲减）**：已报税的退货单可一键添加「出口货物退运」负数明细行，申报表出口金额与免抵退结果自动重算。
- **申报流转**：待申报 → 已申报 → 已退税，支持取消申报、取消退税；删除申报自动回滚进项发票匹配状态。

### 3.9 预警提醒与消息中心

- **业务事件即时提醒**：订单审核、转直采、转外发、通知发货、发货完成、应收生成等关键节点，系统自动给对应角色发站内消息。
- **账期定时预警**：每天早上 9 点（应用启动时还会补扫一次）自动扫描应收/应付：**将到期（提前 7 天）**提醒催收/付款，**已逾期**升级提醒；红字应收不参与，避免误报。
- **规则可配置**：提醒点开关、标题/内容模板（支持 {order_no}/{amount}/{due_date} 占位符）、收件角色、提前天数、去重窗口全部可在管理端调整。
- **消息中心**：右上角铃铛未读红点（30 秒轮询），点击消息直达关联单据；管理端可按用户/角色/提醒点/单据类型全量查询通知发送记录。

### 3.10 系统管理

- **用户管理**：创建/停用/删除用户、重置密码（编辑时密码留空即不修改）。
- **角色权限（RBAC）**：菜单级权限码体系；内置 7 个系统角色——**管理员、销售经理、采购经理、生产经理（生产功能下线后仅保留批次追溯等基础权限）、财务经理（发票/应收应付/收付款/库存）、库管员、只读（仅驾驶舱）**，也可自建角色按模块勾选权限；管理员永远拥有全部权限。
- **权限安全**：所有业务写接口按业务域校验权限、读接口按「本域 + 业务引用域」授权——低权限角色（如库管员）无法通过任何途径读写非授权域数据。
- **AI 配置**：配置 AI 引擎（DeepSeek / OpenAI 或兼容接口）、模型、温度、系统提示词；API Key 加密存储、界面脱敏显示。
- **企业微信配置**：预留的企业微信应用配置（Secret 加密存储），推送通道为后续版本钩子，当前未启用。

### 3.11 AI 助手（Matsu）

系统右下角全局悬浮球，任何页面随时呼出对话助手：

- **查询**：自然语言查客户/供应商/物料/产品/应收/应付/发票/库存/待审核单据，结果表格化展示。
- **操作**：对话式创建采购/销售订单（支持一次多明细行）、录收付款、录发票、审核/反审核——与页面操作走同一套业务规则（自动核销、自动生成应付应收、发票号查重等）。
- **教学**：内置操作手册检索，问「采购入库怎么操作」直接返回对应章节。
- **安全**：AI 能用的工具按**当前用户权限**过滤，无权限的操作既不展示也不能执行（双重校验）；所有写操作自动记录审计日志（谁、在哪个页面、让 AI 做了什么、结果如何）。

## 四、技术亮点

| 亮点 | 说明 |
|------|------|
| 销售订单两路分流 | 一单多行、行行独立选路（直采/外发），互斥锁定；成品采购由销售驱动、材料采购独立、领料出库才挂销售单，覆盖外贸企业「贸易 + 委外」混合业态 |
| 批次成本核算 | 库存按批次记成本，出入库全部带前后数量/成本快照的流水，毛利直接核算到发货批次 |
| 单据链闭环与反向操作 | 转单、退回、反审核、红冲、取消全链路覆盖，且「下游没退，上游不能动」由系统强制保证 |
| 财务业务一体化 | 开票自动生成应收/应付、账期自动算、收款付款自动核销、红冲全程留痕 |
| 免抵退申报引擎 | 出口端报关行 + 采购端进项发票双端匹配，退货负数申报自动冲减 |
| AI 助手 Matsu | 权限感知的 Function Calling 智能体，能查、能做、能教，全程审计 |
| 预警提醒系统 | 事件埋点 + 定时账期扫描双引擎，规则配置化，去重防扰 |
| 多币种支持 | 订单/发票外币记账、汇率自动获取（国内源）与手工维护双通道，自动折算本位币 |
