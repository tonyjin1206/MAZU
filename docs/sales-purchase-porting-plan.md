### 0.6.1 统一入库模型 StockInOrder（🔴 与主线冲突，会议必议）

### 0.6.2 转直采/转委外流程（🔴 与主线备货方式模型冲突）

- 合作者：销售明细行「转直采」→ 只推送单据到**转采购页**（按 BOM 展开物料、损耗默认 10%、按供应商自动拆单）→ 生成采购单；「转外发」对称；**不经过生产订单**
- 主线：生产订单 → 确认备货方式（自产/委外/外购）→ 外购型推**采购需求 PR** → 采购转单
- **冲突点**：合作者绕开生产订单/PR 环节，销售明细行直达采购；主线外购必须挂 MO。两条链路并存会导致同一订单两套状态口径（合作者四档"未采购/部分/已转/完成" vs 主线 MO 状态机）
- 会议需定：**转直采是否独立于生产订单存在**（合作者模型）还是必须挂 MO（主线模型）

## 3. 迁移优先级矩阵

```
高价值低风险 → 先做：A-1 参数设置、A-2 发货后端核心、A-9 合计栏、A-6 扩展字段、A-5 关联客户
高价值中风险 → 评估：A-7 收发存、A-3 双栏 UI
中价值大工程 → 最后：A-4 列拖拽、A-8 采购主从
需业务确认  → B 组测试评优、D 组讨论
冲突        → C 组不移植
```
