TRADE-ERP

外贸企业一体化管理平台

采购 · 销售 · 生产 · 库存 · 财务 · 退税 — 全链路数字化

Python FastAPI Vue 3 Element Plus SQLite JWT Auth
核心功能模块
📦

采购管理

采购订单→ 采购入库→ 采购发票→ 应付账款→ 付款
  • 供应商管理，采购订单全生命周期
  • 采购入库支持多次/超量入库，自动生成批次
  • 单据自动编号，状态自动流转
🚀

销售管理

销售订单→ 销售发货→ 销售发票→ 应收账款→ 收款
  • 批次出库，库存成本自动核算
  • 未开票金额自动跟踪，防止重复开票
  • 应收账款账龄自动计算
⚙️

生产管理

生产订单→ 派产→ 发料→ 完工→ 成品入库
  • BOM 自动展开物料需求
  • 多批次发料，每步操作可反退
  • 成本自动归集，入库即算单位成本
📊

库存管理

  • 库存余额实时查询（数量 + 金额）
  • 库存流水全程追溯（来源单据可穿透）
  • 批次管理，支持正向/反向追踪
💳

财务管理

  • 应收/应付双维度管理（汇总 + 明细）
  • 账龄自动计算，逾期预警
  • 收款/付款与应收/应付自动核销
  • 加工费发票独立管理
📋

退税管理

  • 按申报期管理退税批次
  • 关联销售发票，一键生成申报
  • 进度跟踪：申报→审核→已退税

核心特色
🔄

全链路可追溯

每一笔业务从订单到收付款，所有单据号可点击穿透查看上下游，运营全程透明。

⏪

每步可撤销

发料可取消、完工可反退、入库可取消、订单可关闭/恢复。放心操作，不怕出错。

📊

管理驾驶舱

现金收支、应收/应付账龄、销售毛利可视化，关键指标一目了然，支持穿透明细。

🔢

自动编号体系

所有单据按统一规则自动编号（PO/SO/MO/ST/AP/AR…），格式规范，便于查对。

💰

成本自动流转

材料成本 → 入库成本 → 出库成本 → 销售毛利，全程自动核算，无需手工算账。

⚡

零配置部署

SQLite 本地数据库，无需安装数据库服务。前后端一键启动，即可投入使用。

智能成本核算
🔗

业财一体，成本自动流转

从采购入库的物料成本、到生产环节的加工费用、再到销售出库的存货成本——系统自动追踪每一分钱的流向，无需手工算账、无需 Excel 对账。

物料采购→ 生产领用→ 加工费用→ 成品入库→ 销售出库→ 毛利分析
🎯

每笔订单毛利，一键穿透

驾驶舱中实时查看每笔销售订单的毛利和毛利率。点击即可穿透到成本拆解明细——收入多少、材料成本多少、加工费多少，清清楚楚。
