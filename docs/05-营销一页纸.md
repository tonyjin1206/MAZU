# MTS 妈祖外贸管理系统 —— 一页纸看懂

> **Mazu Trade System v2.8.0** ｜ 轻量级外贸企业管理平台 ｜ 让中小外贸工厂用一套系统管住「接单 → 备货 → 出货 → 收款 → 退税」全链条

## 一、我们解决什么问题？

中小外贸企业的日常：订单在 Excel 里、库存在仓管脑子里、成本在财务月底才算得清、退税材料到处找单据、老板想看数据只能等人报表。**MTS 把这些全部装进一个系统**——单文件部署、一键安装、中文界面、开箱即用，10～200 人的外贸工厂/贸易公司一周内上线。

## 二、五大核心卖点

### 🔀 卖点 1：销售订单「两路分流 + 材料独立」，贸易与委外一张订单全搞定

贸易买进卖出、发加工厂做——多数企业两类单都有，普通 ERP 只会一种。MTS 的销售订单**每一行明细独立选择「转直采 / 转外发」**，两条路线互斥锁定：直采行按成品生成采购订单（买成品，无视 BOM）；委外行不关联采购——材料单独采购入库，委外领料出库时成本才挂回销售单。下游采购单、委外单自动生成、自动串联，业务员零录入。

### 🏭 卖点 2：批次级成本核算，毛利精确到每一笔发货

库存按**批次**记数量和成本，出入库全部留带前后快照的流水；发货出库直接锁定批次成本，驾驶舱**毛利榜按发货单逐笔算「收入 − 出库成本」**，退货自动冲减。老板看到的不再是月底倒挤的模糊利润，而是每单每货的真实盈利，杜绝「账面盈利、实际亏损」。

### 💰 卖点 3：财务业务一体化，账期红冲全自动

开票自动生成应收/应付、到期日自动按客户/供应商账期计算、收付款自动核销、开错票一键**红冲**（自动负数发票+负数应收，全程留痕禁改禁删）、收付款财务**审核锁定**防篡改；应收到期提前 7 天自动提醒、逾期自动升级——催收不靠人记。

### 🤖 卖点 4：AI 助手 Matsu，会话即操作

右下角悬浮球随时呼出：**能查**（自然语言查客户、库存、应收、待审单据，结果即表格）、**能做**（对话式建订单、录收付款、开发票、审核——与页面同一套业务校验）、**能教**（内置操作手册问答）。AI 的能力**严格跟随当前用户权限**，无权限的功能看不见也调不动，每个写操作自动记审计日志。

### 🛃 卖点 5：免抵退申报引擎，退税资料一键归集

生产企业免抵退自动试算（应退税额、免抵税额一键算出）；采购录「增值税专用发票」**自动汇入进项发票池**；申报表出口端挂报关单商品行、采购端挂进项发票**双端匹配**，防重复申报；出口退运自动生成负数冲减行、申报表自动重算。（注：退税界面在本版本暂未开放菜单入口，能力已就绪。）

## 五、客户价值

- **少招人不加班**：转单自动生成下游单据、需求数量自动算、到期日自动算、汇率自动拉——业务员/采购员/财务从重复录入中解放。
- **资金看得住**：应收/应付账龄实时呈现，到期前 7 天自动预警，逾期自动升级；账期、信用额度、审核锁定三重防线。
- **利润算得准**：批次成本贯穿采购入库 → 材料领料 → 发货出库，毛利钻取到每一笔发货，退货自动冲回。
- **货账对得上**：批次追溯一条时间线看到每批货的进出单据，盘点差异自动出盘盈亏，责任到单。
- **退税不丢钱**：进项发票自动归集、申报双端匹配防重复、退运负数自动冲减——该退的税一分别漏。
