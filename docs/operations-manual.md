# Mazu Trade System (MTS) — 操作手册

> 面向日常业务操作人员 | 版本 2.8.0 — 销售订单三分支流程版

---

## 一、业务流程总览

外贸ERP的完整业务从**接单**开始，到**收款**结束。v2.8.0 的关键变化是：**销售订单审核后不再自动生成生产订单**，而是由业务员为每条明细行选择**三条独立路线之一**（转直采 / 转外发 / 转生产-自产）。

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        MTS 完整业务流程（三分支）                      │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ① 销售订单（审核）───→ 明细行三路分流（只能走其一）                     │
│       │                                                                  │
│       ├─【转直采】→ ② 销售订单转采购 → ③ 采购订单 → ④ 采购入库         │
│       │                                        │                        │
│       ├─【转外发】→ ⑥ 销售订单转委外 → ⑦ 委外订单 → ⑧ 成品入库         │
│       │                                        │                        │
│       └─【转生产-自产】→ ⑨ 生产订单 → ⑩ 派产/发料/完工 → ⑪ 成品入库     │
│                                                                         │
│       （三路最终都到 ⑫ 销售发货）                                        │
│       ↓                                                                  │
│  ⑫ 销售发货（通知发货→库管出库）→ ⑬ 销售开票 → ⑭ 应收 → ⑮ 收款        │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

**三条路线，按业务实际选：**

| 分支 | 适用场景 | 明细行状态 | 下游入口 |
|------|---------|-----------|---------|
| 转直采 | 贸易型：买 A 卖 A，无生产/委外 | 已通知入库 | 采购管理 → 销售订单转采购 |
| 转外发 | 委外型：买原料交加工厂做成品 | 已通知外发 | 委外管理 → 销售订单转委外 |
| 转生产-自产 | 自有生产：车间自产 | 生产中 | 生产管理 → 生产订单 |

> **重要**：一条明细行**只能走一条路线**（互斥）。转生产后不能再转直采/转外发，反之亦然。选择前请先想清楚这批货怎么来。

## 二、先跑通全流程所需的基础数据

在开始做业务之前，先按以下顺序录入基础数据。

### 2.1 录入物料（原辅材料）

**场景举例：** 你们公司生产（或委外加工）"智能控制器"，需要用到 PCB 电路板、电阻、塑料外壳等。先把它们录入系统。

**操作步骤：**
1. 左侧菜单 **基础档案 → 原辅材料**
2. 点击 **"新增原材料"**
3. 填写：

| 字段 | 填写示例 | 说明 |
|------|---------|------|
| 物料编码 | M001 | 自己编的编号 |
| 物料名称 | PCB电路板 | |
| 规格 | 双面板 10×10cm | |
| 型号 | FR-4 | |
| 单位 | 片 | **重要**：所有单据自动带出 |
| 采购单价 | 15 | 采购入库后自动更新 |
| 分类 | 原材料 | |

4. 点击"确定"保存，重复录入其他物料

### 2.2 录入产品

**场景举例：** 你们公司卖"智能控制器"，这就是产品。

**操作步骤：**
1. **基础档案 → 产品档案** → 点击 **"新建"**
2. 填写：

| 字段 | 填写示例 |
|------|---------|
| 编码 | PRD001 |
| 名称 | 智能控制器 |
| 规格 | 标准型 |
| 单位 | 台 |
| 销售单价 | 120 |

### 2.3 录入客户

**场景举例：** 产品卖给"上海电子科技有限公司"。

1. **基础档案 → 客户管理** → **"新增客户"**
2. 填写客户编码、名称、联系人、联系方式

### 2.4 录入供应商（含委外商）

供应商有两种用途：

| 供应商类型 | 举例 | 用途 |
|-----------|------|------|
| 原材料 | 深圳电子元件有限公司 | 卖原材料的 |
| 委外加工 | 东莞SMT加工厂 | 做委外加工的（转外发时用） |

1. **基础档案 → 供应商管理** → **"新增供应商"**
2. 填写编码、名称、类型（选"原材料"或"委外加工"）
3. 供应商类型选"委外加工"即视为委外商，无需单独维护

### 2.5 设置 BOM（产品物料清单 + 工艺路线）

**场景举例：** 生产一台"智能控制器"需要：PCB电路板 ×2片、电阻套装 ×1包、塑料外壳 ×1个；工艺路线：SMT贴片 → 组装测试。

**操作步骤：**
1. **基础档案 → BOM管理**
2. 上方产品列表选中"智能控制器"
3. 下方「组成材料」页签点 **"新增材料"**：

| 物料 | 用量 | 说明 |
|------|:----:|------|
| PCB电路板 | 2 | 一台用2片 |
| 电阻套装 | 1 | |
| 塑料外壳 | 1 | |

4. 下方「工艺流程」页签点 **"添加工序"**，按顺序添加工序（选工序、设加工单价、默认供应商）：

| 工序 | 加工单价 | 默认供应商 | 说明 |
|-----|:--------:|:--------:|------|
| SMT贴片 | 10元/台 | 东莞SMT加工厂 | 委外工序（可选供应商） |
| 组装测试 | 6元/台 | （空=自产） | 自产工序 |

5. 点击"确定"保存

### 2.6 设置工序

**功能位置：** 基础档案 → 参数设置 → 加工工序 tab

工序默认**自产**（无供应商）。只有需要委外的工序才在 BOM 工艺流程里给它指定供应商。

### 2.7 设置币种/汇率

系统预置常用币种（人民币/美元/欧元/日元/英镑/港币/澳元），也可自行维护。支持手工维护与腾讯财经自动获取。

## 三、端到端业务操作详解

### 第一步：销售订单（全部业务的起点）

**一句话：** 客户下单了，你先录销售订单，审核。

**场景举例：** 上海电子科技公司订购 50 台智能控制器，单价 ¥120。

**操作步骤：**
1. **销售管理 → 销售订单** → 点击 **"新建订单"**
2. 填写：

| 字段 | 填写 | 说明 |
|------|------|------|
| 客户 | 上海电子科技有限公司 | 先添加客户 |
| 产品 | 智能控制器 | 选完带出单价 |
| 数量 | 50 | |
| 含税单价 | ¥120 | |

3. 系统自动计算：含税金额 = 50 × 120 = **¥6,000**
4. 点击"保存" → 订单状态：**待审核**
5. 点击 **"审核"** → 状态变为 **"已审"**

> **关键（v2.8.0）：** 审核后**不会生成生产订单**。每条明细行状态变为 **"未生产"**，接下来你需要在明细行上选择路线（第二步）。

---

### 第二步：明细行选路线（转直采 / 转外发 / 转生产-自产）

**一句话：** 订单审核后，为每条明细行选一条路线——货是要直接买、委外加工、还是自己生产。

**场景举例：** 这 50 台智能控制器，如果你们是贸易公司就"转直采"买成品；如果委托加工厂做就"转外发"；如果自己有车间就"转生产-自产"。

**操作步骤：**
1. 在销售订单明细行（选中已审订单）找到"智能控制器"这一行
2. 按业务实际点一个按钮：

| 按钮 | 说明 | 明细行状态变 |
|------|------|-------------|
| **转直采** | 直接买来卖（成品贸易） | 已通知入库 |
| **转外发** | 委托加工厂做 | 已通知外发 |
| **转生产-自产** | 自己车间生产 | 生产中 |

> **注意：** 三个按钮只显示在"未生产"状态的明细行上。选了一条路线后，另外两个按钮就消失（互斥）。

**接下来三步分别怎么走：**
- 选了 **转直采** → 进入「**第三步：销售订单转采购**」
- 选了 **转外发** → 进入「**第五步：销售订单转委外**」
- 选了 **转生产-自产** → 进入「**第七步：生产订单**」

---

### 第三步：销售订单转采购（转直采路线）

**一句话：** 明细行转直采后，货要去采购，在"销售订单转采购"页办采购。

**操作步骤：**
1. **采购管理 → 销售订单转采购**
2. 看到来自销售订单的待采购明细行
3. 点 **"采购"** → 生成采购订单（按 BOM 展开或按供应商拆单）
4. 在采购订单页审核

**场景举例（贸易型，无 BOM）：** 50 台智能控制器直接买成品，生成采购单 → 审核 → 成品入库。

> **后续：** 采购单审核后，到「**采购入库**」收货（成品从"成品入库"页、原料从"原料入库"页）。明细行收货后状态→ 已入库。

---

### 第四步：采购订单 → 采购入库（所有路线通用备料）

**一句话：** 要采购原料/成品，下采购单、收货入库。

**场景举例：** 需要 PCB 电路板 100 片（生产/委外 50 台的原料）。

**操作步骤：**
1. **采购管理 → 采购订单** → **"新建订单"** → 选供应商、物料、数量、单价 → 保存 → 审核
2. **采购管理 → 采购入库**（或 成品入库/原料入库 页）→ 选采购单 → 填本次入库数量 → 确认

**入库后系统自动完成：**
```
① 生成入库单号：PR-20260723-001
② 生成批次号
③ 库存增加
④ 更新物料采购单价
⑤ 订单状态更新（全部入库后）
```

> 支持多次入库、超订单量入库。入错了可"取消"（未消耗）或"红冲"（已消耗）。

---

### 第五步：销售订单转委外（转外发路线）

**一句话：** 明细行转外发后，货要委托加工厂做，在"销售订单转委外"页安排工序和加工商。

**场景举例：** 50 台智能控制器委托加工。工艺路线：SMT贴片（东莞SMT加工厂）→ 组装测试（自产）。

**操作步骤：**
1. **委外管理 → 销售订单转委外**
2. 看到**工序层级关系面**：最左产品，向右按顺序展开各工序节点（SMT贴片 → 组装测试）
3. 每个工序节点配置：
   - **加工商**（默认工序默认供应商）
   - **加工单价**
   - **委外数量**
   - **供料方式**：己方提供 / 包工包料
   - **认领原料**（己方提供时需认领）
4. 点 **"生成委外订单"** → 每道工序生成一张委外订单（一工序一供应商，草稿）
5. 去 **委外订单页** 审核

**供料方式说明：**
| 方式 | 说明 |
|------|------|
| 己方提供 | 你提供原料，需"认领原料"（扣库存） |
| 包工包料 | 加工厂提供原料，不认领、不出库 |

> **重要：** 委外订单审核后，**只有末道工序**生成成品待入库单（中间工序只记加工成本）。这样成品数量不会重复。

**后续：** 末道工序收货 → 成品入库 → 明细行状态 → 已入库。

---

### 第六步：委外订单 → 加工费发票

**一句话：** 加工厂开加工费发票，登记进系统生成应付。

**场景举例：** 东莞SMT加工厂开 ¥500 加工费发票。

**操作步骤：**
1. **委外管理 → 加工费发票** → **"新建"**
2. 选委外订单，金额完全由工序数据计算，保存 → 生成应付账款

---

### 第七步：生产订单（转生产-自产路线）

**一句话：** 明细行转生产后，货要自己车间做，生成生产订单。

**场景举例：** 50 台智能控制器自己车间生产。

**操作步骤：**
1. 明细行点 **"转生产-自产"** → 自动生成生产订单（状态：待确认）
2. **生产管理 → 生产订单** → 找到该订单
3. 点 **"维护"** → **确认备货方式**（自产/外购）
4. (自产) → 展开 BOM → 派产 → 进生产工作台

**生产工作台操作：**
1. **派产**：分配工序（待排产 → 已排产）
2. **发料**：选择物料批次发料（扣库存）
3. **完工**：每道工序加工完点"完工"
4. **入库**：所有工序完工后点"入库"，填材料成本+加工费，成品入库
5. 明细行状态 → 已入库

> 每步操作都可逆：反派产、取消发料、反退、取消入库。

---

### 第八步：销售发货（所有路线汇合）

**一句话：** 货齐了，发给客户。两步化：业务员通知发货 → 库管出库。

**场景举例：** 50 台智能控制器发货给上海电子科技公司。

**操作步骤：**
1. **销售管理 → 销售发货** → **"通知发货"**（只填数量，不扣库存）
2. 库管在 **库存管理 → 成品出库** 页按批次发货（扣库存）
3. 业务员判断 → **"发货完成"**（必须有出库记录）

**退货：** 必须已有出库记录才能退。退回原批次、原成本，回退订单已发数量。

---

### 第九步：销售开票 → 应收账款

**一句话：** 发货后给客户开发票，系统自动生成应收账款。

**场景举例：** 给上海电子科技公司开 ¥6,000 发票。

**操作步骤：**
1. **销售管理 → 销售发票** → **"新建"**
2. 选客户 → 选销售订单 → 系统显示未开票金额 ¥6,000
3. 填含税金额 → 保存 → 自动生成应收账款 ¥6,000

**发票红冲（开错票 / 退货冲销）：**
1. 找到已开票蓝字发票 → 点 **"红冲"**
2. 系统按原票**全额负数**生成红字发票 + 自动生成**红字应收**（负数）
3. 红字票禁改禁删、已红冲蓝字票禁删

> 已开票订单发生退货时，系统会提示需同步红冲发票。

---

### 第十步：收款 / 付款 / 核销

**收款（客户付了）：**
1. **销售管理 → 收款** → **"新建"**
2. 选客户 → 勾选要核销的应收 → 填收款金额 → 保存 → 应收状态更新

**退款（退钱给客户）：**
1. **应收账款** → 找到**红字应收**（余额红色负数）→ 点 **"退款"**
2. 填退款金额（不能超过应退余额）→ 确认 → 生成负数收款单核销红字应收

**核销转移（清理红字应收）：**
1. **应收账款** → 红字应收 → 点 **"核销转移"**
2. 选同客户正余额应收 → 填转移金额 → 确认 → 红字被抵扣，正余额"已收"增加

**付款（付给供应商）：**
1. **采购管理 → 付款** → **"新建"**
2. 选供应商 → 勾选应付 → 填付款金额 → 保存

---

### 第十一步：退税申报（出口业务）

**场景举例：** 报关出口后，做免抵退申报。

**操作步骤：**
1. **退税管理 → 退税申报** → **"新建申报期"**（填年度、月份）
2. 关联发票 / 报关单商品行
3. 提交申报 → 状态：已申报
4. 完成退税 → 状态：已退税

**负数申报（退货冲减出口额）：**
1. 已报税退货单打标"已报税"
2. 申报表点 **"添加退货冲减（负数申报）"** → 选已报税退货单 → 确认
3. 系统生成"出口货物退运"负数明细行，冲减出口额 & 免抵退结果自动重算

## 四、毛利怎么看

### 4.1 销售毛利计算逻辑

```
销售收入 ¥6,000（卖给客户的价格）
  - 出库成本 ¥3,000（入库时的单位成本 × 发货数量）
  = 销售毛利 ¥3,000
```

### 4.2 在工作台查看

**工作台（首页）** 底部显示每笔发货的毛利，支持穿透查看成本拆解。

### 4.3 成本精度的关键

```
入库成本的准确性 = 决定毛利的准确性

入库时录入的：
  材料成本  ¥2,200  ← 发料/认领成本汇总
  加工费    ¥800    ← 各工序加工费合计
     ↓
  单位成本 = (2,200+800)/50 = ¥60/台
     ↓
  出库50台 × ¥60 = ¥3,000 成本
     ↓
  收入¥6,000 - ¥3,000 = 毛利¥3,000 ✓
```

> 入库时材料成本和加工费要尽量填准（系统会自动结转建议值，一般不用手改）。

## 五、库存盘点（账实核对）

**一句话：** 定期把仓库里实际的数盘一遍，和系统账面数对账，有差异就入账。

**操作步骤：**
1. **库存管理 → 盘点管理** → **"新建盘点"**
2. 选择要盘的仓库 → 系统列出该仓所有有库存的批次（显示账面数）
3. 逐行录入**实盘数**
4. 点 **"提交盘点"** → 确认

**系统自动完成：**
```
实盘 > 账面 → 盘盈：库存 +差异
实盘 < 账面 → 盘亏：库存 -差异
生成盘点流水：stocktake_in / stocktake_out
收发存报表：期初 + 收发 + 盘点 = 期末 ✓
```

> 提交后不可修改/删除；盘亏不能超过账面数。

## 六、常见问题

### Q1：明细行选了路线后还能改吗？

**不能直接改**。三分支互斥（转直采/转外发/转生产-自产三选一）。若要改路线，需先到对应下游页**退回**该明细行（如转直采 → 去「销售订单转采购」退回；转外发 → 去「销售订单转委外」退回），明细行状态回到「未生产」，再重新选路线。

### Q2：委外时"己方提供"材料，库存不够怎么办？

先做 **采购订单 → 采购入库** 补足原料库存，再来委外页"认领原料"。

### Q3：工序完工后发现有问题？

点击 **"反退"** 按钮，工序回到未完工状态，重新处理。

### Q4：开票后发现开错了？

销售发票支持 **"红冲"**。红冲后生成红字发票 + 红字应收；红字票不能改/删。

### Q5：客户只付了部分款？

收款时金额填实际收到的金额即可。应收余额自动更新，下次再核销剩余部分。

## 七、预警提醒（通知铃铛 · 业务联动 · 账期预警）

> 全系统按角色自动推送业务提醒与账期预警，站内消息中心（顶部铃铛）承接。

### 7.1 顶部铃铛

页面右上角**铃铛**：有未读时显示红点数；点开看最近通知；点某条自动**标记已读**并**跳到对应单据**。

### 7.2 业务联动提醒（自动触发）

| 触发 | 提醒谁 | 干什么 |
|------|-------|-------|
| 销售订单审核通过 | 销售经理 | 对明细行做转直采/转外发/转生产，安排发货 |
| 明细行转直采 | 采购经理 | 到「销售订单转采购」下单 |
| 明细行转外发 | 采购经理 | 到「销售订单转委外」安排工序+买原料 |
| 明细行转生产（v2.8.0） | 生产经理 | 到「生产管理」安排排产与发料 |
| 通知发货（待出库） | 库管员 | 到「成品出库」出库 |
| 明细行发货完成 | 销售经理 | 安排开票 |
| 应收生成 | 财务+销售 | 财务入账、销售跟进催收 |

### 7.3 账期预警（每日 09:00 自动扫描）

应收/应付将到期与逾期提醒（红字应收不参与）。规则可在「系统管理 → 通知管理」配置。

## 八、AI 智能助手（Matsu）

AI 助手直接在聊天框里用自然语言操作 ERP。**入口在页面右下角的蓝色 M 悬浮球**，任何页面随时可用。

### 8.1 我能帮你做什么

| 类别 | 试试这么说 |
|------|-----------|
| 查数据 | 「查下客户清单」「查物料PCB」 |
| 查库存 | 「PCB板还有多少」 |
| 审核 | 「有什么待审核的单」「审核采购单PO-xxx」 |
| 下单 | 「采购PCB板100片15块」 |
| 收款/付款 | 「收美国客户5000块」「付给深圳华强3000」 |
| 发票 | 「采购单PO-001发票12345金额5000」 |

> **v2.8.0**：销售订单审核后 AI 会提示明细行需选择转直采/转外发/转生产三条路线之一，不会自动帮你定路线。

### 8.2 三步确认流程

所有创建类操作都会经过三次确认：问清意图 → 缺什么字段问什么 → 完整信息核对后执行。

### 8.3 权限

AI 助手只能做你有菜单权限的操作。没权限的操作 AI 会明确告知，不会执行。所有操作留痕。

## 九、操作注意事项

1. **先想好路线再操作：** 销售明细行三分支互斥，选了一条就不能走另一条。先想清楚这批货怎么来（买/委外/自产）。

2. **每一步操作都可取消：** 发料可取消、完工可反退、入库可取消、订单可反审批——做错了能回退。

3. **下游解锁上游：** 下游单据存在时上游不能变更，先退回下游单据，上游才解锁。

4. **入库时成本填准：** 材料成本和加工费直接影响销售毛利，尽量准确。

5. **委外看供料方式：** 己方提供要认领原料（扣库存），包工包料不用。

6. **基础档案先建好：** 物料、产品、客户、供应商、BOM、工序、币种——都建完了再开始做业务。
