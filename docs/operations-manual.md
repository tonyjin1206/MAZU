# Mazu Trade System (MTS) — 操作手册

> 面向日常业务操作人员 | 版本 2.1 — AI 多明细行新增版

---

## 一、业务流程总览

外贸ERP的完整业务从**接单**开始，到**收款**结束，中间经过生产、委外、采购、入库、开票等环节。下面是完整流程：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        MTS 完整业务流程                              │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ① 销售订单 ──→ ② 生产订单 ──→ ③ 委外工序                               │
│       │                 │            │                                   │
│       │                 │            ├→ ④ 采购订单 → ⑤ 采购入库          │
│       │                 │            │       │            │              │
│       │                 │            │       └→ ⑥ 采购发票 → 应付账款    │
│       │                 │            │                                   │
│       │                 │            ├→ ⑦ 委外发料 → ⑧ 委外完工          │
│       │                 │            │                                   │
│       │                 │            └→ ⑨ 内部工序陆续完工                │
│       │                 │                       │                       │
│       │                 └────────────→ ⑩ 完工入库（成本核算）            │
│       │                                              │                  │
│       └────────────────────────────→ ⑪ 销售开票 → ⑫ 应收账款 → ⑬ 收款  │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

**每一步之间都有明确的推动关系：**
- ① → ②：接了销售订单，推动安排生产
- ② → ③：生产订单展开工序，其中可能有委外工序
- ③ → ④：根据BOM物料需求，采购原材料
- ④ → ⑤：供应商送货后入库
- ⑤ → ⑥：供应商开发票，生成应付
- ③ → ⑦：委外工序需要发料给委外商
- ⑦ → ⑧：委外商加工完返回
- ⑨ → ⑩：所有工序完成后成品入库
- ① → ⑪：发货后给客户开票
- ⑪ → ⑫：开票生成应收账款
- ⑫ → ⑬：客户付款

## 二、先跑通全流程所需的基础数据

在开始做业务之前，先按以下顺序录入基础数据。

### 2.1 录入物料（原辅材料）

**场景举例：** 你们公司生产"智能控制器"，需要用到 PCB 电路板、电阻、塑料外壳等。先把它们录入系统。

**操作步骤：**
1. 左侧菜单 **基础档案 → 原辅材料**
2. 点击 **"新增原材料"**
3. 填写：

| 字段 | 填写示例 | 说明 |
|------|---------|------|
| 物料编码 | M001 | 自己编的编号 |
| 物料名称 | PCB电路板 | |
| 规格 | 双面板 10×10cm | |
| 型号 | FR-4 | |
| 单位 | 片 | **重要**：所有单据自动带出 |
| 采购单价 | 15 | 采购入库后自动更新 |
| 分类 | 原材料 | |

4. 点击"确定"保存，重复录入其他物料

### 2.2 录入产品

**场景举例：** 你们公司卖"智能控制器"，这就是产品。

**操作步骤：**
1. **基础档案 → 产品档案** → 点击 **"新建"**
2. 填写：

| 字段 | 填写示例 |
|------|---------|
| 编码 | PRD001 |
| 名称 | 智能控制器 |
| 规格 | 标准型 |
| 单位 | 台 |
| 销售单价 | 120 |

### 2.3 录入客户

**场景举例：** 产品卖给"上海电子科技有限公司"。

1. **基础档案 → 客户管理** → **"新增客户"**
2. 填写客户编码、名称、联系人、联系方式

### 2.4 录入供应商和委外商

供应商有两种类型：

| 供应商类型 | 举例 | 用途 |
|-----------|------|------|
| 原材料 | 深圳电子元件有限公司 | 卖原材料的 |
| 委外加工 | 东莞SMT加工厂 | 做委外加工的 |

1. **基础档案 → 供应商管理** → **"新增供应商"**
2. 填写编码、名称、类型（选"原材料"或"委外加工"）
3. 供应商类型选"委外加工"即视为委外商（用于生产工序的委外派产），无需单独维护

### 2.5 设置 BOM（产品物料清单）

**场景举例：** 生产一台"智能控制器"需要：PCB电路板 ×2片、电阻套装 ×1包、塑料外壳 ×1个。

1. **基础档案 → BOM管理**
2. 左侧产品列表选中"智能控制器"
3. 右侧点 **"新增材料"**
4. 填：

| 物料 | 用量 | 说明 |
|------|:----:|------|
| PCB电路板 | 2 | 一台用2片 |
| 电阻套装 | 1 | |
| 塑料外壳 | 1 | |

5. 点击"确定"保存

### 2.6 设置工序

**场景举例：** 生产过程需要经过 SMT贴片 → 组装测试 两道工序，其中 SMT贴片 外包给东莞SMT加工厂。

1. **基础档案 → 工序管理** → **"新增工序"**
2. 填写：

| 工序 | 加工单价 | 说明 |
|-----|:--------:|------|
| SMT贴片 | 10元/台 | 委外工序 |
| 组装测试 | 6元/台 | 自产工序 |

3. 保存

### 2.7 设置币种/汇率

系统预置常用币种（人民币/美元/欧元/日元/英镑/港币/澳元），也可自行维护。

1. **基础档案 → 币种/汇率**（系统已预置 7 个常用币种）
2. **新增币种**：编码（如 `THB`）、名称、符号；首个本位币把"本位币"开关打开（本币用于成本/报表汇总）
3. **新增汇率**：选择币种 → 填"兑本位币汇率"（如 USD 兑 CNY = 7.10）→ 生效日期
4. 汇率按生效日期留档，业务单据取当日最新汇率换算

> 币种被销售/采购/财务单据引用后不可删除；修改汇率不影响已生成单据金额。

## 三、端到端业务操作详解

### 第一步：销售订单（全部业务的起点）

**一句话：** 客户下单了，你先录销售订单。

**场景举例：** 上海电子科技公司订购 50 台智能控制器，单价 ¥120，要求 7月底交货。

**操作步骤：**
1. **销售管理 → 销售订单** → 点击 **"新建订单"**
2. 填写：

| 字段 | 填写 | 说明 |
|------|------|------|
| 客户 | 上海电子科技有限公司 | 先添加客户 |
| 产品 | 智能控制器 | 选完带出单价 |
| 数量 | 50 | |
| 含税单价 | ¥120 | |
| 预计发货日 | 2026-07-30 | |

3. 系统自动计算：含税金额 = 50 × 120 = **¥6,000**
4. 点击"保存" → 订单状态：**待审核**
5. 点击 **"审核"** → 状态变为 **"已审"**

> **下一步是什么：** 订单审核后，需要安排生产。进入 **第二步：创建生产订单**。

---

### 第二步：生产订单（从销售订单推动）

**一句话：** 销售订单审核了，你现在需要为这批产品创建一个生产订单。

**场景举例：** 客户订了 50 台智能控制器，你要安排车间生产。

**操作步骤：**
1. **生产管理 → 生产订单** → 点击 **"新建"**
2. 填写：

| 字段 | 填写 | 说明 |
|------|------|------|
| 关联销售订单 | 选中 SO-xxx | 可选，建立关联关系 |
| 产品 | 智能控制器 | |
| 生产数量 | 50 | |
| BOM | 选择"智能控制器"的BOM | 自动展开物料清单 |
| 计划完成日 | 2026-07-28 | |

3. 点击"保存" → 状态：**待排产**

**保存后系统自动做了三件事：**
```
① 根据BOM自动生成物料需求清单（生产50台需领用的材料清单）
   PCB电路板 100片、电阻套装 50包、塑料外壳 50个

② 根据产品关联工序自动生成工艺路线
   工序1: SMT贴片（委外） → 工序2: 组装测试（自产）

③ 状态设为"待排产"，等待派产
```

> **下一步是什么：** 生产订单建好但还没安排具体开工，需要先**派产**（分配工序）。同时，如果某些物料库存不足，要**采购备料**。进入 **第三步** 和 **第四步**（可以并行做）。

---

### 第三步：采购订单（为生产备料）

**一句话：** 生产需要原材料，库存不够的就要采购。

**场景举例：** 仓库里 PCB 电路板只有 20 片，但生产 50 台需要 100 片，差 80 片。需要向深圳电子元件公司采购。

**这步和下一步的关系：**
```
生产需求：100片 PCB电路板
仓库现有：20片
需要采购：80片  ← 这就是采购订单的数量
```

**操作步骤：**
1. **采购管理 → 采购订单** → 点击 **"新建订单"**
2. 填写：

| 字段 | 填写 | 说明 |
|------|------|------|
| 供应商 | 深圳电子元件有限公司 | |
| 物料 | PCB电路板 | 选完自动带出名称/单位 |
| 数量 | 80 | 按需采购量 |
| 单价 | ¥15 | 含税单价 |
| 税率 | 13% | 默认13% |

3. 系统计算：含税金额 = 80 × 15 = **¥1,200**
4. 可以继续添加其他需要采购的物料
5. 点击"保存" → 审核 → 状态：**已审核**

> **下一步是什么：** 采购订单发给供应商后，等供应商送货。到货后做 **采购入库（第五步）**。

---

### 第四步：委外安排（工序派产 + 确定委外工序）

**一句话：** 生产订单需要派产，分配工序。如果工序有委外商，就确定好谁来加工。

**场景举例：** 智能控制器需要经过 SMT贴片（委外给东莞SMT加工厂）→ 组装测试（自产）。

**操作步骤：**
1. **生产管理 → 生产工作台**（或生产订单详情页）
2. 找到状态"待排产"的订单行（MO-001）
3. 点击 **"派产"**
4. 弹窗中分配工序：

| 工序 | 类型 | 委外商 | 加工单价 | 加工数量 |
|-----|:----:|:------:|:--------:|:--------:|
| SMT贴片 | 委外 | 东莞SMT加工厂 | ¥10 | 50 |
| 组装测试 | 自产 | （空） | ¥6 | 50 |

5. 点击"确定" → 订单状态变为 **"已排产"**
6. 工作台显示每道工序的行，各自有独立按钮

> **下一步是什么：** 委外工序需要把原材料发给委外商。同时自产工序也准备开始。进入 **第六步：委外发料**。

---

### 第五步：采购入库（供应商送货了）

**一句话：** 供应商送货到了，点收入库。库存就有了。

**场景举例：** 深圳电子元件公司送来了 80 片 PCB 电路板。

**操作步骤：**
1. **采购管理 → 采购入库** → 点击 **"新建入库"**
2. 选择采购订单 PO-xxx → 自动加载物料明细
3. 选择仓库（原材料仓）
4. 填写本次入库数量：

| 物料 | 订单数量 | 已入库 | 本次入库 |
|------|:-------:|:-----:|:--------:|
| PCB电路板 | 80 | 0 | 80 |

5. 点击 **"确认入库"**

**入库后系统自动完成：**
```
┌─────────────────────────────────────────────┐
│ ① 生成入库单号：PR-20260723-001            │
│ ② 生成批次号：20260723-001                │
│ ③ 库存增加：PCB电路板 +80片，总库存≈100片   │
│ ④ 自动更新物料采购单价为 ¥15               │
│ ⑤ 采购订单状态更新为"已完成"（全部入库后）   │
└─────────────────────────────────────────────┘
```

> 注意：支持多次入库。如果只到了 50 片，先入库 50 片，剩下的下次再入。

**入错了怎么办？**（两种方式，都在入库单列表的操作列）

| 方式 | 适用场景 | 效果 |
|------|---------|------|
| **取消** | 刚入完、批次还没被发料/发货消耗 | 整单回滚（补一条冲销流水，报表平账） |
| **红冲** | 批次已被消耗（发过料等） | 生成负向红冲单，只冲当前剩余的库存；订单已入库数量同步回退 |

> 红冲是"负向入库"，原单保留、审计可查。已开采购发票的订单不能取消/红冲（先处理发票）。

> **下一步是什么：** 供应商寄来发票后，录入采购发票（第六步）；同时有了库存就可以发料给委外商了（第七步）。

---

### 第六步：采购发票 → 应付账款

**一句话：** 供应商寄来发票了，录入系统，系统自动生成应付账款。

**场景举例：** 深圳电子元件公司寄来了 ¥1,200 的增值税专用发票。

**操作步骤：**
1. **采购管理 → 采购发票** → 点击 **"新建"**
2. 填写：

| 字段 | 填写 | 说明 |
|------|------|------|
| 供应商 | 深圳电子元件有限公司 | |
| 关联采购订单 | PO-xxx | 选择后自动显示未开票金额 |
| 发票金额 | ¥1,200 | 含税金额 |
| 发票类型 | 专票 | |

3. 点击"保存"

**系统自动完成：**
```
┌──────────────────────────────────────────────┐
│ ① 生成应付账款 ¥1,200                       │
│    应付单号：AP-20260723-001                 │
│    来源：采购发票 PO-xxx                     │
│    状态：未付款                              │
│                                              │
│ ② 采购订单"未开票金额"减少 ¥1,200             │
│    订单未开票金额归零                         │
└──────────────────────────────────────────────┘
```

> **下一步是什么：** 到期需要付款给供应商。进入 **付款环节**（第十步之后统一说）。

---

### 第七步：委外发料（把材料发给委外商）

**一句话：** 委外工序需要材料，把原材料发给委外商。

**场景举例：** SMT贴片需要 PCB 电路板 100 片，发给东莞SMT加工厂。

**为什么这步很重要：**
```
┌── 委外商（东莞SMT加工厂）没有自己的材料 ──────────┐
│                                                     │
│  委外加工是"来料加工"：                          │
│  委外商只负责加工，材料是你们的。                    │
│  所以要把材料发过去。                                │
│                                                     │
│  发料 = 库存从"原材料仓"转移到"委外商"             │
│  完工 = 加工好的半成品从委外商返回                   │
└─────────────────────────────────────────────────────┘
```

**操作步骤：**
1. **生产管理 → 生产工作台**
2. 找到 SMT贴片 工序行（状态：已排产）
3. 点击 **"发料"**
4. 弹窗显示该工序需要的物料：

| 物料 | BOM用量 | 本次发料 | 库存 |
|------|:-------:|:--------:|:---:|
| PCB电路板 | 100 | 100 | ✅ 100片 |

5. 选择出库批次（系统自动推荐先进先出）
6. 点击 **"确认发料"**

**系统自动完成：**
```
┌─────────────────────────────────────────────┐
│ ① 生成发料单号                              │
│ ② 扣减原材料仓库存：PCB电路板 -100片        │
│ ③ 记录材料成本 = 100 × ¥15 = ¥1,500        │
│ ④ 更新生产订单"已转出材料成本"              │
│ ⑤ SMT贴片工序状态 → 待完工                  │
└─────────────────────────────────────────────┘
```

> **如果发错了：** 点击 **"取消发料"** 可以回退库存。

> **下一步是什么：** 委外商收到材料后开始加工，加工完送回，做 **委外完工（第八步）**。

---

### 第八步：委外完工（委外商加工完返回）

**一句话：** 委外商加工好了，把半成品收回来。

**场景举例：** 东莞SMT加工厂贴片完成了，50 台智能控制器的 PCB 板全贴好了。

**操作步骤：**
1. **生产管理 → 生产工作台**
2. 找到 SMT贴片 工序行（状态：已发料）
3. 点击 **"完工"**
4. 确认后，该工序状态变为 **"已完工"**

**完工后系统处理：**
```
┌─────────────────────────────────────────────┐
│ ① SMT贴片工序状态：已完工                    │
│ ② 如果该工序不在最后一道，半成品流转到       │
│    下一道工序（组装测试）                     │
│ ③ 更新生产订单"总加工费" += 50×¥10 = ¥500   │
└─────────────────────────────────────────────┘
```

> **如果完工后发现有问题：** 点击 **"反退"** 可以回到待完工状态。

> **下一步是什么：** 下一道工序（组装测试）可以开始了。如果所有工序都完工了，就做 **成品入库（第九步）**。

---

### 第九步：内部工序完工（多步生产）

**一句话：** 自产工序做完一道确认一道。

**场景举例：** 组装测试是第二道工序，全部 50 台组装完毕。

**操作步骤：**
1. **生产工作台** → 找到"组装测试"工序行
2. 点击 **"完工"**

如果生产订单有更多道工序，每道工序依次点击"完工"，直到所有工序都完成。

**工序流转示意：**
```
SMT贴片（委外）→   完工    → 半成品进入组装测试工序
组装测试（自产）→   完工    → 成品准备入库
      ↓                         ↓
  所有工序都完工后    →  可以点"入库"了
```

> **下一步是什么：** 所有工序都完工后，做 **完工入库（第十步）**，成品入库的同时计算成本。

---

### 第十步：完工入库 + 成本核算

**一句话：** 所有工序做完了，成品入库，同时算出这批产品的成本。

**场景举例：** 50 台智能控制器全部加工完成，入库到成品仓。

**操作步骤：**
1. **生产工作台** → 找到已完成所有工序的订单行
2. 点击 **"入库"**
3. 填写入库信息：

| 字段 | 填写 | 说明 |
|------|------|------|
| 入库数量 | 50 | 支持多次入库 |
| 仓库 | 成品仓 | |
| 材料成本（可留空） | ¥2,200 | **留空=自动结转**：系统按已发料成本汇总×本次入库占比自动算出（建议）；手填可覆盖 |
| 加工费（可留空） | ¥800 | **留空=自动结转**：按已完工工序加工费自动算出；手填可覆盖 |

> 自动结转逻辑：剩余投入成本 ×（本次入库数量 ÷ 剩余未入库数量），最后一次入库自动转完剩余。这样成本一定和实际发料、工序完工对得上。

4. **系统自动计算：**
   ```
   单位成本 = (¥2,200 + ¥800) ÷ 50 = ¥60/台
   ```

**已开票/已收款/已报税的退货处理（v2.5.2）：**

| 场景 | 操作 |
|---|---|
| 已发货未开票 | 直接退货，仅红字发货单 + 库存回库 |

## 五、毛利怎么看

### 5.1 销售毛利计算逻辑

```
销售收入 ¥6,000（卖给客户的价格）
  - 出库成本 ¥3,000（入库时的单位成本 × 发货数量）
  = 销售毛利 ¥3,000
  = 毛利率 50%
```

### 5.2 在工作台查看

**工作台（首页）** 底部显示每笔发货的毛利：

```
订单号     客户       产品    收入      成本     毛利     毛利率
SO-001    上海电子   智能     ¥6,000   ¥3,000   ¥3,000   50% ✓
```

### 5.3 成本精度的关键

```
入库成本的准确性 = 决定毛利的准确性

入库时录入的：
  材料成本  ¥2,200  ← 发料成本汇总
  加工费    ¥800    ← 各工序加工费合计
     ↓
  单位成本 = (2,200+800)/50 = ¥60/台
     ↓
  出库50台 × ¥60 = ¥3,000 成本
     ↓
  收入¥6,000 - ¥3,000 = 毛利¥3,000 ✓
```

> 所以入库时材料成本和加工费要尽量填准（系统会自动结转建议值，一般不用手改）。

## 六·五、库存盘点（账实核对）

**一句话：** 定期把仓库里实际的数盘一遍，和系统账面数对账，有差异就入账，保证账实一致。

**操作步骤：**
1. **库存管理 → 库存收发存** → **"盘点管理"** tab → **"新建盘点"**
2. 选择要盘的仓库 → 系统自动列出该仓所有有库存的批次（显示账面数）
3. 逐行录入**实盘数**（数出来是多少就填多少，自动保存）
4. 点 **"提交盘点"** → 确认

**系统自动完成：**
```
实盘 > 账面 → 盘盈：库存 +差异（按批次成本入账）
实盘 < 账面 → 盘亏：库存 -差异（按批次成本出账）
生成盘点流水：stocktake_in / stocktake_out（来源=盘点单号）
收发存报表：期初 + 收发 + 盘点 = 期末 ✓ 账实一致
```

> - 提交后不可修改/删除（想再调整就新建一张反向盘点）。
> - 盘亏不能超过账面数（实盘不能为负）。
> - 盘点前建议先做完当天的收发业务，避免差异。

## 七、常见问题

### Q1：采购入库时能只入一部分吗？

可以。支持**多次入库**和**超订单量入库**。每次填写"本次入库"数量即可。比如订了 80 片，先到 50 片就先入库 50 片，下次到了再入库剩下 30 片。

### Q2：系统自动填充采购单价，我怎么修改？

采购入库时系统会自动从采购订单带出单价。如果实际价格不同，入库后可以去物料档案手动修改采购单价。

### Q3：委外发料时库存不够怎么办？

看哪个物料不够，先做**采购订单 → 采购入库**补足库存，再来发料。这就是为什么采购备料要走在委外发料前面。

### Q4：工序完工后发现有问题？

点击 **"反退"** 按钮，工序会回到未完工状态，可以重新处理。

### Q5：入库后想改成本？

如果刚入库，点击 **"取消入库"** 取消本次入库，重新录入。如果是历史数据，需要手动调整。

### Q6：开票后发现开错了？

销售发票支持 **"作废"** 操作。作废后未开票金额恢复，应收账款同步冲销。

### Q7：客户只付了部分款？

收款时金额填实际收到的金额即可。应收余额会自动更新，状态变为"部分收款"。下次对方再付款时，再核销剩余部分。

### Q8：一个采购订单对应多个入库、多个发票？

完全可以。系统支持多次入库和多次开票，未入库/未开票的数量和金额会自动累计。

**场景举例：** 客户同时订购了智能控制器 50 台（¥120/台）和智能传感器 20 个（¥80/个）。

**操作方式：**
1. 说：「销售智能控制器50台单价120+智能传感器20个单价80」
2. AI 确认产品列表
3. 一次性创建含 2 行明细的销售订单

> **与传统手动操作的区别：**
> 传统方式：每行明细独立添加 → 保存 → 再添加下一行
> AI 方式：一句话包含所有行，AI 自动拆分 → 确认 → 一起创建

### 9.4 提示

- 你可以一句话给多个信息，比如「采购PCB板100片单价15块供应商深圳华强」
- 说错了可以改口，「不对，改成销售」
- 查询结果以数据库为准，AI 不会编造数据

## 十、操作注意事项

1. **顺序很重要：** 业务单据之间有依赖关系。采购入库必须先有采购订单，委外完工必须先发料。系统会控制操作顺序。

2. **每步操作都可取消：** 发料可取消、完工可反退、入库可取消、订单可反审批——做错了能回退。

3. **入库时成本填准：** 材料成本和加工费直接影响后面的销售毛利，尽量准确。

4. **工序完工按顺序：** 工序必须按序号依次完工，不能跳过上一道直接做下一道。

5. **及时开票录发票：** 采购发票影响应付账款准确性，销售发票影响应收账款和毛利计算。

6. **基础档案先建好：** 物料、产品、客户、供应商、BOM、工序——这些都建完了再开始做业务。
