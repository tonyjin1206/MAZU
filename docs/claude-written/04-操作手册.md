## 一、登录系统

1. 打开浏览器，在地址栏输入公司提供的系统网址（本机演示为 `http://localhost:5173`）。
2. 输入账号和密码，点击「登录」。
   - 系统首次安装的默认管理员账号为 `admin`，密码 `admin123`，**登录后请立即在「系统管理 → 用户管理」修改密码**。
3. 登录后进入「工作台」（驾驶舱）。左边是功能菜单——**你能看到哪些菜单由管理员分配的角色决定**，看不到的菜单说明你的角色没有该权限，请联系管理员。
4. 右上角铃铛是「消息中心」，有红点表示有新提醒（如订单待审核、应收将到期），点击即可查看并跳到对应单据。
5. 右下角蓝色圆球是 AI 助手「Matsu」，任何页面都可以点开，用日常话问它，比如「帮我查一下杭州飞天的应收」「采购入库怎么操作」。

**退出登录**：点击右上角头像 → 退出。

## 二、基础数据录入

> 基础数据是一切业务的起点，请先把档案建全再开始做单。
> 通用规则：**编码自动生成，不要自己编**；**档案做过业务后不能删除，只能停用**——停用后以后开单选不到，但历史单据不受影响。

### 2.1 客户档案

菜单位置：基础档案 → 客户管理

1. 点「新增」，系统已自动预生成客户编码（编码栏灰色不可改）。
2. 逐项填写：

| 栏目 | 怎么填 |
|------|--------|
| 中文名称 / 英文名称 | 客户公司名称，建议用全称 |
| 国家/地区、地址 | 下拉的国家选项来自「参数设置」，可让管理员补充 |
| 联系人 / 电话 / 邮箱 / 税号 | 据实填写 |
| 付款条件 | TT（电汇）/ LC（信用证）/ DP / DA |
| 账期（天） | ⚠️ 重要：开票后系统按「开票日 + 账期天数」自动算收款到期日，请和客户合同一致 |
| 信用额度 | 用于人工控制赊销规模 |

3. 点「保存」。客户做过订单后不能删除，只能「停用」（系统会弹确认框提醒停用后果）。

### 2.2 供应商档案

菜单位置：基础档案 → 供应商管理。填法与客户类似，另有三个关键字段：

| 栏目 | 怎么填 |
|------|--------|
| 供应商类型 | 原材料 / 委外 / 辅料。⚠️ **委外加工商也建在这里，类型选「委外」**，做委外时从这个类型里选加工商 |
| 账期（天） | 采购开票后按「开票日 + 账期」自动算付款到期日 |
| 付款条件 / 税号 / 地址 | 据实填写 |

### 2.3 原辅材料

菜单位置：基础档案 → 原辅材料

1. 点「新增」，填：编码（自动）、名称、大类、小类、型号、规格、单位、采购参考价。
2. 大类/小类的下拉选项来自「参数设置」的材料类别字典。
3. 「默认供应商」可以选，转采购时会自动带出参考。

### 2.4 产品档案与 HS 编码

菜单位置：基础档案 → 产品档案

1. 点「新增」，填：编码（自动）、中文名、英文名、规格、型号、单位、销售价、预估成本。
2. **HS 编码**：直接在 HS 编码栏位选择或输入。⚠️ 系统没有单独的 HS 编码管理页面——输入一个新 HS 编码保存后，系统会自动建立 HS 档案；选择已有 HS 编码会**自动带出征税率、退税率、法定单位**，这些税率以后报关和退税都会用到，请核对正确。
3. 「是否可外购」：勾选后，这个成品也可以作为采购品被买进来（用于转直采/备货采购）。
4. 保存后，如该产品对特定客户有专属料号/价格，可在「产品客户资料」中再维护一份（两步保存：先存产品主档，再维护客户资料）。

### 2.5 BOM（产品用料清单）与工艺路线

菜单位置：基础档案 → BOM 管理。BOM 是采购需求计算、生产发料、委外认领材料的**计算依据**，务必准确。

1. 上半部分选产品，然后添加**材料行**：选材料、填「单位用量」（做 1 个产品用多少）和「损耗率 %」。
2. 下半部分添加**工艺行**：按加工先后顺序添加工序，可「上移/下移」调整顺序。工序来自「基础档案 → 工序管理」，并给每道工序填加工单价（供生产/委外算加工费参考）。
3. 点「保存」整体提交。
4. ⚠️ BOM 改了只影响**之后**的新订单，已生成的生产/委外订单不会跟着变。

### 2.6 工序、参数、仓库

- **工序管理**（基础档案 → 工序管理）：新增工序，编码自动按 GX 生成。当前工序都按「自产工序」管理。
- **参数设置**（基础档案 → 参数设置）：系统里所有下拉框的选项都在这里维护，按「页签」分组（供应商类型、材料类别、计量单位、付款方式、国家、仓库类型、加工工序等）。新增时大类编码自动按 01、02 递增，小类按 0101、0102 递增。⚠️ 删除参数时系统会提示：有业务数据引用的只能停用，不能删除。
- **仓库管理**（基础档案 → 仓库管理）：新增仓库，编码自动按 WH 生成，**类型必须选对**：「原辅料仓库」存材料，「成品仓库」存产品。⚠️ 仓库类型建错会导致收货时自动匹配不到仓库，退货也麻烦；一个类型建议至少建一个仓库。

### 2.7 币种与汇率

菜单位置：基础档案 → 币种/汇率

- 系统预置人民币（本位币）、美元、欧元、日元、英镑、港币、澳元。
- 左侧卡片区点「获取最新汇率」，系统自动从行情网站拉取当天汇率入库（每天早上 9 点系统也会自动拉一次）；拉取不到的币种（如日元交叉盘）请手动维护。
- 手动维护：选币种 → 填「兑本位币汇率」→ 选生效日期 → 保存。同一个币种同一天只能有一条，重复录入会被拦截。
- 做外币订单时会自动带出最新汇率，也可在订单上手工改。

## 三、销售全流程（报价 → 订单 → 备货分流 → 发货 → 开票 → 收款）

整条链路：**报价单 → 销售订单（审核）→ 每行明细选路线（转直采 / 转外发 / 转生产）→ 通知发货 → 仓管出库 → 确认发货完成 → 开销售发票 → 收款核销**。

### 3.1 报价单（可选）

基础档案式的快速报价：销售管理菜单下新建报价单，选客户、产品、数量、外币单价、有效期，状态「有效」。客户接受后转成正式订单。

### 3.2 创建销售订单

菜单位置：销售管理 → 销售订单

1. 点「新增销售订单」：
   - 选**客户**；订单号自动生成（SO 开头）。
   - 选**币种**，系统带出汇率（可改）；**付款条件**选 TT/LC/DP/DA。
   - 添加明细行：每行选**产品**、填**数量**和**单价**（外币价）。一个订单可以有多个产品行。
2. 保存后订单为「待审核」。
3. 点该订单的「审核」→ 订单变「已审」。⚠️ **审核只是确认订单成立，不会自动安排生产和采购**——接下来要为每一行明细选择备货方式（见 3.3）。

**明细行后续可变更吗？** 可以。已审订单的明细行点「变更」可改数量、新单价（系统重算订单金额）；不想做的行可以「停售」。⚠️ 如果该行已经转了采购/委外/生产，系统会提示你先去下游退回，才能变更。

### 3.3 选择备货方式（三路分流）——本系统最核心的操作

订单审核后，每一行明细独立选择三条路线之一（**三选一，选定后互斥**）：

| 路线 | 适用场景 | 点哪个按钮 | 之后去哪办 |
|------|----------|------------|------------|
| **转直采** | 贸易型：产品直接买来卖给客户 | 明细行「转直采」（系统弹确认框） | 采购管理 → 销售订单转采购 |
| **转外发** | 委外加工型：把活发给加工商 | 明细行「转外发」 | 委外管理 → 销售订单转委外 |
| **转生产** | 自产型：自己车间做 | 明细行「转生产」（需订单已审核） | 生产管理 → 生产订单 |

选完后明细行状态会变化（如「已通知入库」「已通知外发」「生产中」），对应岗位会收到站内提醒：
- 转直采 → 提醒采购经理；转外发 → 提醒采购经理（委外归口采购）；转生产 → 提醒生产经理。
- ⚠️ 一行明细只能走一条路线。如果选错了，在下游还没做单据前可以退回（比如到「销售订单转采购」页点「退回」），退回后明细行回到「未生产」，可重新选择。

### 3.4 发货（两段式，业务与仓库分工）

1. **业务员**：销售订单页对该行点「通知发货」→ 生成发货单（SD 开头，状态「待出库」），仓管员收到提醒。
2. **仓管员**：到 库存管理 → 成品出库，找到待出库的发货单，点「出库」：选出库批次（下拉里会显示每个批次的可用数量和「已锁定给哪个订单」的数量，⚠️ 被锁定的数量不能发给别人）、确认出库。库存立即按批次扣减。
3. **业务员**：回到销售发货页，对明细行点「发货完成」确认。此后的开票、毛利统计都以确认过的发货为准。
4. **客户退货**：在销售发货页对该发货单做「退货」：货自动退回**原批次**、成本按原发货成本冲回，驾驶舱毛利自动减少。
   - ⚠️ 若该订单已开票，系统会提示「已开票需同步红冲发票」，请通知财务处理；
   - ⚠️ 若该批货已申报退税，退货单会自动标记「已报税」，财务下月申报时系统自动带出负数冲减。

### 3.5 开销售发票（含开错票怎么办）

菜单位置：销售管理 → 销售发票

1. 对已发货的订单点「开票」：填发票号、金额，系统校验**开票金额不能超过该订单未开票金额**。
2. 保存后自动生成「应收账款」，到期日 = 开票日 + 客户账期；销售和财务都会收到「应收已生成」提醒。
3. **开错票 → 红冲**：对已开票的蓝字发票点「红冲」，系统自动生成一张**等额负数发票和负数应收**，原票标记「已红冲」。⚠️ 红字票不能改也不能删——如果红冲错了，只能联系管理员处理，所以红冲前务必核对票号。
4. 应收账款页可以看到每笔应收的余额：红色负数是红字应收，绿色正数是正常应收。

### 3.6 收款

菜单位置：销售管理 → 收款管理

1. 点「新增收款」：选客户、填金额、收款日期、付款方式；选择要核销的应收单（不选则按应收到期日先后自动核销）。
2. 保存后生成收款单（CR 开头），对应应收的余额自动减少，收清的应收自动变「已收款」。
3. **退款**：给客户退钱时录一张**负数金额**的收款单（红字显示），用于冲销红字应收。
4. **财务审核**：收款单核实无误后点「审核」——审核后这张收款单就**锁定**了，谁都不能改不能删；真录错了先「取消审核」再改。这是财务防篡改机制，请审核前核对清楚。

## 四、采购全流程

整条链路：**销售订单转采购（或采购需求）→ 采购订单审核 → 入库 → 开票 → 付款**。

### 4.1 销售订单转采购

菜单位置：采购管理 → 销售订单转采购

1. 列表自动列出所有业务员「转直采/转外发」过来的明细行（显示产品、批次号、采购状态：灰=未采购、橙=部分采购、蓝=已转采购订单、绿=已完成）。
2. 点某行进入**采购需求清单**：系统按该产品 BOM 自动算出应买材料及数量（订单数 × 单位用量 ×（1+损耗））。⚠️ 如果提示「该物料不在 BOM 内」，请先让资料员补 BOM。
3. 为每行材料选**供应商**、填**单价**（系统带出材料档案里的参考采购价）。不同材料可以给不同供应商——提交时系统**自动按供应商拆成多张采购订单**。
4. 损耗率默认 10%（允许范围 0～50%）：意思是允许最多买到「需求量 × 1.1」。超量系统直接拦截并提示还能买多少。
5. 全部采购完成后（或业务确认不用再买时），点「完成采购」人工关闭该行；点错了可「取消完成」继续追加。

### 4.2 采购需求（外购型生产订单推来的）

生产上「转外购」的产品会推送采购需求到这里。点「生成采购订单」填供应商、单价、税率、交期即可，数量已按需求预填可改。需求关闭后对应生产订单回到待采购，可重新推送。

### 4.3 采购订单

菜单位置：采购管理 → 采购订单

- 新建订单：选供应商、日期、币种、税率，添加明细（材料或可外购的成品）。
- 「审核」后订单才能入库；「反审核」仅在没有任何入库单和发票时可用。
- **改单**：只有「待审核」的订单能改。⚠️ 由销售订单转来的订单**不允许直接编辑**（保证与销售单联动一致），要改就先「退回」再重新转。
- **退回订单**：点「退回」——有未退回的待入库单时系统会提示先去原料/成品入库页把待入库单退回；已有关联入库单或发票的不能删。
- 列表上每个订单都显示：已入库/未入库金额、已开票/未开票金额、已付/未付金额，采购进度一目了然。

### 4.4 入库（两条通道，别走重）

采购订单审核后，每个明细行有两种去向（二选一，系统防重复）：

- **转原料库入库**：材料类明细用。点「转原料库」生成待入库单，然后到 库存管理 → 原料入库 收货。
- **转成品库入库**：成品采购（转直采的货）用。点「转成品库」生成待入库单（可关联销售批次），到 库存管理 → 成品入库 收货。
- ⚠️ 已经转过待入库单的明细**不能**再走「采购入库」页直接入库，系统会提示去对应入库页收货——这是为了防止同一批货入两次账。

**收货操作**（原料入库 / 成品入库页）：
1. 在「待入库」列表点「收货」：选仓库（系统按仓库类型自动匹配）、填实收数量，可**分批收**（收满自动完成）。
2. 收货即生成批次号、按订单单价记入库存成本。
3. 「退回」= 整单退回（仅未收货时可退）；「退数量」= 已入库后冲减数量；「确认完成」= 不再收货，手工关闭。

### 4.5 采购入库单的取消与红冲

菜单位置：采购管理 → 采购入库

- **取消入库**：批次还没被任何领料/发货/盘点动过时可以整单取消，库存自动回滚。
  - ⚠️ 如果提示「批次已被全部领用」，请先到生产工作台/委外页**反退对应的发料单**，再回来取消；
  - 如果批次被用了一部分，系统会提示走「红冲」。
- **红冲**：生成一张负数入库单把数量冲回去，支持多次部分红冲。被红冲的原单标记「已红冲」，审计痕迹完整。

### 4.6 采购发票与应付

菜单位置：采购管理 → 采购发票

1. 对已入库的订单点「新增发票」：填发票号（⚠️ 系统查重，重号会被拦截）、金额、税额、类型。
2. 保存后自动生成**应付账款**，到期日 = 开票日 + 供应商账期。
3. ⚠️ 发票类型选「增值税专用发票 / 海关进口缴款书 / 农产品收购发票」这三种可抵扣类型时，会**自动登记到退税的进项发票池**（财务退税时直接用）。
4. 删除发票时，对应的应付和进项发票登记会一起删除；但已付过款的发票要先删付款单才能删。
5. **付款**：采购管理 → 付款管理 → 新增付款，选供应商、金额、要核销的应付单。付款单同样有财务「审核」锁定机制。
6. 应付账款页可查每张应付的余额和账期，还有「应付-付款」对照明细表。

## 五、生产全流程（自产）

整条链路：**销售明细「转生产」→ 生成生产订单 → 确认备货方式 → 展开 BOM → 派产 → 发料 → 工序完工 → 成品入库**。

### 5.1 生成生产订单与备货方式

1. 销售订单明细行点「转生产」后，生产管理自动生成一张生产订单（MO 开头），明细行变「生产中」。
2. 打开订单，先点「确认备货方式」：
   - **自产** → 订单进入「待排产」，走本章流程；
   - **外购** → 订单进入「待采购」，不进车间，改去「采购需求」推采购（见 4.2）。
   - ⚠️ 备货方式只能确认一次，确认前不能展开 BOM、不能排产。

### 5.2 展开 BOM 与派产

1. 点「展开 BOM」：系统按产品 BOM 生成材料需求清单（计划量 = 订单数 × 用量 ×（1+损耗））和工序路线（按工艺路线模板）。
2. 点「派产」：订单「待排产 → 已排产」，每道工序变「待发料」，销售明细与订单变「生产中」。⚠️ 派产会**锁定工艺路线**（弹窗有提示），派产前请确认工序和材料清单都维护好了。
3. 还没派产（待排产）的订单可以删除或修改；已派产想撤回用「反派产」（已发过料的不能反）。

### 5.3 发料（领料）

菜单位置：生产管理 → 生产工作台（推荐，一屏看所有订单×工序）

1. 在对应工序点「发料」：选材料、批次（优先用先进库的批次）、数量。确认后：
   - 生成发料单（MI 开头），库存按批次扣减；
   - 工序「待发料 → 已发料」。
2. 发多了？点「取消发料」把料退回库存（生成退料流水）；工序已完工报了的需先撤销完工。
3. AI 助手也能帮你发料：对 Matsu 说「给 MO-xxxx 发 3 毫米钢板 50 张」。

### 5.4 工序完工

1. 每道工序做完后点「工序完工」：填加工单价、数量，系统记加工费（金额 = 单价 × 数量）。
2. 第一道完工后下一道自动变「待发料」，继续发料、完工；**全部工序完工后订单变「已完成」**。
3. 报错了用「反退」撤销本次完工报工。

### 5.5 完工入库（成品入库）

1. 工序全部完工后，在生产工作台点「完工入库」：选成品仓库、填入库数量。
2. 系统自动生成入库单（FG 开头）和成品批次。
3. **成本结转**：弹窗里成本栏「留空」即可——系统按「本次入库占剩余应入库的比例」自动把材料费和加工费分摊进批次，最后一批自动全额结转。懂成本的师傅也可以手工填。
4. 入库后销售明细变「已生产」，后续按第三章发货流程走。
5. ⚠️ 入库错了要「取消入库」：仅限这个批次还没被发货/盘点动过；动过的批次走销售退货通道处理。

## 六、委外流程

整条链路：**销售明细「转外发」→ 转委外页配置工序和加工商 →（己方提供材料时先认领原料）→ 审核生成委外订单和加工费应付 → 加工商做完 → 待入库单收成品入库**。

### 6.1 配置委外

菜单位置：委外管理 → 销售订单转委外

1. 列表显示所有「转外发」的明细行（委外状态四色标识：未开始/部分/已生成/已完成）。
2. 点开一行，进入配置画面：
   - 系统按产品工艺路线列出**工序节点**（从左到右的层级关系图）。每个节点可指定加工商（只能选「委外」类型供应商）、委外数量、加工单价——**每道工序生成一张独立的委外订单**，方便按加工商分别结算。
   - 这次不想委外的工序，点该节点「删除」即可；删错了点底部「恢复全部工序」一键加回。
   - **供料方式**（整个订单选一个）：
     - **己方提供**：材料由我方发给加工商 → 必须先做「认领原料」（见 6.2）；
     - **包工包料**：加工商自己备料 → 不用认领。
3. 全部配置完成、校验通过（页面底部会提示还有哪些没配好）后，点「生成委外订单」→ 生成 WO 开头的委外订单（草稿）。

### 6.2 认领原料（己方提供时必做）

1. 点「认领原料」按钮：系统按「成品数 × BOM 用量 ×（1+损耗）」列出每种材料**应领数量**和仓库总可用量。
2. 逐种材料填认领数量（不超过仓库可用），确认后系统自动从仓库**跨批次扣料**并记出库流水。
   - ⚠️ 材料不够会明确提示缺多少，请先完成采购；
   - 认领错了在委外订单删除前可以退回（材料自动回原批次）。

### 6.3 委外订单的审核与管理

菜单位置：委外管理 → 委外订单

1. 草稿订单可「维护」（改加工商、单价、数量）——⚠️ 仅「待确认」状态可改。
2. 点「审核」：
   - 订单变「已审核」，自动生成**加工费应付账款**（按加工商分单）；
   - 只有**最后一道工序**的委外单会自动生成成品「待入库单」（中间工序不生成，防止半成品当成品入库）。
3. 「反审核」：已付过款或已部分入库的不能反。
4. 「删除」：仅「待确认」可删。已认领的原料会自动退回原批次，销售明细行回到「未生产」（可重新选路线）——删除确认框里会写清楚这些后果。
5. 加工商交付后：到 库存管理 → 原料入库/成品入库 的待入库列表收货入库，收满后委外订单自动「已入库」，明细行推进到可发货状态。

## 七、库存管理操作

### 7.1 库存查询（收发存）

菜单位置：库存管理 → 库存收发存

- 默认显示**当前快照**：每个仓库每种物料/产品的批次余额（数量、单价、金额）。
- 切「期间」视图并选日期区间：显示**期初 + 收入 − 发出 = 期末**，适合月度对账。
- 对任一批次点「追溯」：一条时间线看清这批货什么时候从哪张单进来、被哪张单出出去。盘点对不上时第一个就来这里查。

### 7.2 出入库操作一览

| 操作 | 页面 | 要点 |
|------|------|------|
| 原料入库（采购/委外/生产待入库） | 库存管理 → 原料入库 | 收货自动匹配仓库、生成批次；支持分批 |
| 成品入库（直采/自产/委外成品） | 库存管理 → 成品入库 | 收满自动完成；批次可直接用销售批次号 |
| 原料出库（手动领用） | 库存管理 → 原料出库 | 用于非生产领料（如样品、报销料耗）；系统按批次先进先出扣减；MU 开头的单可「退回」 |
| 成品出库（发货出库） | 库存管理 → 成品出库 | 与销售「通知发货」联动；批次下拉显示锁定数量；支持出库退回 |

### 7.3 盘点

菜单位置：库存管理 → 盘点管理

1. 点「新建盘点」：选仓库，系统**自动带出该仓库全部批次的账面数**，进入明细。
2. 逐批次录「实盘数量」，输完自动保存。
3. 发现「账外批次」（仓库有货但系统没账）：点「新增」直接加一行，账面数按 0 算，**成本必须填**。
4. 核对差异无误后点「提交盘点」：
   - 有差异 → 自动生成盘盈/盘亏流水并更新库存；
   - 没有差异 → 系统提示无需提交；
   - 盘亏数量不能超过账面数。
5. ⚠️ 提交后盘点单锁定，不能改不能删；草稿状态才能删除。
6. 盘完后如果发现差异异常，用「批次追溯」查这批货的进出流水。

## 八、退税申报操作

> ⚠️ **版本说明**：退税（生产企业免抵退）的后端能力在本系统中已完整实现，但**当前版本（v2.8.0）界面上暂未开放退税菜单**（功能代码保留，计划后续版本发布）。以下操作流程供功能开放后使用，财务人员现阶段请按原有方式申报。

功能开放后的使用流程：

1. **进项发票自动归集**：采购录入「增值税专用发票」等可抵扣发票时，已自动登记到退税进项发票池，无需重复录入。
2. **免抵退试算**：填出口 FOB 金额、征/退税率、内销税额、进项税额、上期留抵，系统自动算出应退税额、免抵税额等全部结果。
3. **建申报表**：按「所属期 + 批次」新建（单号 TS-年月-批次）。
4. **添加明细行（双端匹配）**：
   - 出口端：选**已放行/已结关**的报关单商品行，商品、数量、FOB 金额、退税率自动带出；
   - 采购端：选进项发票，凭证号、税号自动带出；
   - 每行已选过的报关行和发票不能再选（防重复申报）。
5. **出口退运冲减**：已报税的退货可一键添加「出口货物退运」负数行，申报表出口额与退税额自动重算。
6. **申报流转**：待申报 → 提交（已申报，锁定）→ 录入实际退税额完成「已退税」；均可反向取消；删除申报表（仅待申报）会自动把进项发票恢复为「未匹配」。

## 九、常见问题 FAQ

**Q1：单据删不掉/按钮是灰的？**
每种单据都有状态规则（如采购订单只有「待审核」能删、发货要仓库出库后才能确认）。系统弹出红色提示时会写明原因和正确做法，照提示先处理下游单据即可。

**Q2：客户/供应商/产品想删掉重建？**
做过业务的档案不能删除，请用「停用」。历史单据需要保留这些档案。

**Q3：审核后发现订单写错了？**
销售订单审核后不能整体反审核；明细行可通过「变更」改数量/单价，不需要的行「停售」。涉及下游（采购/委外/生产）的先去下游退回。

**Q4：明细行选了「转直采」还能改「转生产」吗？**
可以，但必须先退掉下游：到「销售订单转采购」页点「退回」（没生成采购单时直接退回；已有采购单要到采购订单页先退采购单）。退回后明细行回「未生产」，即可重新选路线。

**Q5：入库时提示「仓库档案不存在或已停用」？**
说明选的仓库没建或停用了。到 基础档案 → 仓库管理 新增（类型选「原辅料仓库」或「成品仓库」）后再收货。

**Q6：收货时怎么没有自动带出仓库？**
仓库是按「类型」自动匹配的，请确认仓库类型建对：材料收货匹配「原辅料仓库」，成品收货匹配「成品仓库」。

**Q7：采购数量能不能多买一点？**
可以。销售订单转采购默认允许超买 10%（需求量 × 1.1），转采购页可调整损耗率（0～50%）。超过上限系统拦截——这是防止多采购占压资金的刻意设计。

**Q8：开票金额填多少？**
销售开票不能超过该订单「未开票金额」（订单总额 − 已开票累计）；开错票不要删除，用「红冲」生成负数发票。

**Q9：收款/付款录错了怎么办？**
只要财务还没点「审核」，都可以修改或删除（删除会自动回滚应收/应付余额）。已审核的先「取消审核」。

**Q10：库存数和实物对不上？**
按顺序排查：① 库存收发存切换「期间」视图看差异发生的时间段；② 用批次追溯查进出流水；③ 做一次盘点，系统自动出盘盈/盘亏。常见原因是出库时选错批次或收货数量录错。

**Q11：应收账龄里出现负数（红色）？**
那是红字应收（红冲发票产生的），是正常的。需要把它和同客户的正余额应收对平时，用应收页的「核销转移」。

**Q12：汇率不对？**
基础档案 → 币种/汇率，点「获取最新汇率」立即拉取当天行情，或手工维护。拉取不到的币种（如日元）手工填。

**Q13：AI 助手能替我做单吗？做错了算谁的？**
AI 助手 Matsu 能查数据、创建订单/收款/付款/发票、审核、发料、入库，且**只能用你有权限的功能**。它执行的每个写操作都会留下审计日志（谁下的指令、做了什么）。它和你手工操作走同一套校验，做错同样能按流程退回/红冲。

**Q14：忘了密码？**
联系管理员在 系统管理 → 用户管理 重置（编辑用户时密码留空表示不修改，填新密码即重置）。

**Q15：退税菜单怎么没有？**
见第八章版本说明：退税功能已就绪但当前版本未开放界面入口，等待后续版本发布。
